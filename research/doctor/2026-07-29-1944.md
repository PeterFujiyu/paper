### Check 8 — auto mode is not the default

No `permissions.defaultMode` is set in any scope, no managed policy, and auto mode isn't disabled. Proposal: add to `~/.claude/settings.json`:

```json
"permissions": { "defaultMode": "auto" }
```

Auto mode delegates routine permission decisions to a safety classifier instead of prompting each time. It must live in the user file — an `"auto"` default in project or local settings is ignored as repo-controllable. It applies to every project, and it cannot lock anyone out: if auto mode is unavailable at startup (unsupported model, org-side kill switch), the CLI falls back to default mode with a notice.
