# 02 · 分析框架：认知 / UX 心理学原理

> 这些原理是后续审计与建议（03、04）的"标尺"。每条都标注了它在博客阅读场景里意味着什么。来源见 README。

---

## A. 关于"读起来轻松"

### A1. 处理流畅性（Processing Fluency）
人脑会把"加工越省力"的刺激自动评价得**更正面、更可信**。版面越易读，读者越觉得内容"对、靠谱、值得读"。
→ 对博客：测量宽度、行高、对比度、字体选择、留白，直接影响读者对**内容质量**的潜意识判断。

### A2. 美学-可用性效应（Aesthetic–Usability Effect）
看起来更美的界面会被认为**更好用**，且用户对它的小毛病更宽容。
→ 对博客：精致的排版会"借"给内容信任额度。

### A3. 衬线体与长文阅读
衬线的小笔画为眼睛提供**水平流动的引导**，长文阅读中减少眼疲劳、利于行间衔接。
→ 对博客：Paper 用衬线正文是**正确**的（与 Anthropic 一致），应保留。

### A4. 测量宽度 / 行长（Measure）
单行约 **50–75 字符**（理想 ~66）时换行最稳、视线回扫最省力；过宽会让眼睛"找不到下一行行首"。
→ 对博客：这是 Paper 当前最直接的可读性问题（见 03）。

## B. 关于"怎么扫、怎么找"

### B1. F 型扫描（F-Pattern）
面对文字密集页，用户先横扫顶部、再沿左侧下行、中部再横扫一次，形成 F 形热区。
→ 对博客：重要信息放顶部横带；强标题/要点贴左侧竖线；中部用有吸引力的小标题。

### B2. 希克定律（Hick's Law）
选项越多，决策越慢。
→ 对博客：导航/链接要少而精。Paper 的极简导航（Writing / Contact）**做得好**，应保持。

### B3. 米勒定律 / 分块（Miller's Law / Chunking）
工作记忆容量有限（~7±2），信息应分块。
→ 对博客：用 section 小标题 + 留白把长文切块，降低认知负荷。

### B4. 雅各布定律（Jakob's Law）
用户把"别处见过的模式"带到你的站。符合惯例 = 零学习成本。
→ 对博客：文章页的"分类标签 / 封面图 / 相关内容"是读者已熟悉的博客惯例，缺失会让页面显得"不完整"。

### B5. 菲茨定律（Fitts's Law）
目标越大越近，越易点中。
→ 对博客：可点击区域（文章卡片、按钮）要够大、热区要整块。

---

## C. 关于"被记住、被吸引"

### C1. 冯·雷斯托夫效应 / 孤立效应（Von Restorff Effect）
一组相似项里，**唯一与众不同**的那个最易被记住、最先被注意。
→ 对博客：在近乎无彩的版面里，**一个**保留强调色 = 注意力磁铁。这正是 Anthropic 赤陶色的逻辑。Paper 目前**完全无彩**，等于浪费了这个最强工具。

### C2. 序列位置效应（Serial Position：首因 + 近因）
列表中开头和结尾的项最被记住。
→ 对博客：文章列表的第一篇、文章正文的开头与结尾，是高价值位置。

### C3. 可供性（Affordance / Signifiers）
元素要"看起来就像它能做的事"。链接要看起来可点。
→ 对博客：Paper 正文链接用 `color: inherit`（见 03），可点击信号偏弱。

---

## D. 关于"读完、回来"

### D1. 目标梯度效应（Goal-Gradient Effect）
越接近目标，完成动机越强。可见的进度指示能加速完成。
→ 对博客：**阅读进度条 / 阅读时长**能提升读完率。Paper 已经在**后台**算完读率，却不给读者任何进度反馈——白白错过。

### D2. 蔡格尼克效应（Zeigarnik Effect）
未完成的任务在脑中留存更久，制造"想继续"的张力。
→ 对博客：结尾的"相关内容 / 下一篇"利用这种张力把读者留在站内。

### D3. 峰终定律（Peak–End Rule）
人对体验的记忆由**高峰**与**结尾**主导，而非全程平均。
→ 对博客：文章**结尾**极其重要。Paper 现在的结尾只有"← Back to writing"，是一个平淡甚至略显冷清的收尾。

### D4. 社会证明（Social Proof）—— 含反向风险
他人的行为是行为线索（浏览量、完读率）。**但低数字是负面社会证明**："3 views / 12% completion"会主动劝退读者。
→ 对博客：Paper 在每篇文章公开展示 viewCount 与完读率，需要权衡——高数字是助力，低数字是反噬。

---

## E. 关于"控制感与一致性"

### E1. 一致性与标准（Consistency）/ 用户控制
用户期望设置被记住、行为可预测。
→ 对博客：Paper 的暗色模式**刷新即丢失**、不跟随系统——破坏一致性与控制感（见 03）。
