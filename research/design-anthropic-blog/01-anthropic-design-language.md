# 01 · Anthropic 设计语言拆解

> 来源：用户提供的 4 张 anthropic.com 截图 + 网络检索（见 README 信息源）。

Anthropic 的视觉系统刻意远离"科技公司常见的、略带压迫感的神经网络美学"，转而呈现为**一本被认真对待的学术期刊**——人文关怀 + 技术工艺，而不是初创公司落地页。

---

## 1. 色彩（Color）

整体**近乎无彩（achromatic）**，把全部"色彩预算"押在极少量暖色强调上。这是 Anthropic 最重要的一招。

| 角色 | Hex | 说明 |
|------|-----|------|
| 浅背景 | `#faf9f5` | 不是纯白，而是"良好光线下旧纸"的米色羊皮纸调 |
| 深色/深背景/正文 | `#141413` | 近黑炭灰，暗色模式背景 |
| 中灰 | `#b0aea5` | 次级元素、辅助文字 |
| 浅灰 | `#e8e6dc` | 细微背景/分隔 |
| **强调·赤陶橙** | `#d97757` | **唯一主强调色**，被克制地保留，大量场景里甚至不出现 |
| 强调·蓝 | `#6a9bcc` | 次级强调（多用于非文字图形） |
| 强调·绿 | `#788c5d` | 三级强调（多用于非文字图形） |

**关键洞察**：彩色几乎只用在**非文字形状**（插图、图标、数据可视化里的高亮，如 81k 专题中被点亮的丹麦），正文与 UI 几乎全靠黑/灰/米三色和**字体**承担личность。这制造了"克制中的一抹温度"——赤陶色读起来像"智识的温暖"，而非科技的攻击性。

---

## 2. 字体（Typography）—— 双声部系统

Anthropic 用**两款定制字族**做完所有性格塑造，这是它区别于普通极简站的核心：

- **Styrene A**（无衬线 / grotesque，定制名 *Anthropic Sans*）——标题、副标题、导航、UI。Styrene 是 Berton Hasebe 的一次"比例实验"，`f j r t` 等字符偏窄、被拉伸、略呈方形，识别度高。
- **Tiempos**（衬线，Klim Type Foundry，定制名 *Anthropic Serif*）——正文长文、专题大标题（如"What 81,000 people want from AI"）。

**"衬线 + grotesque"的搭配本身就是信号**：它读起来像研究机构 / 学术出版，而不是 SaaS 公司。

层级靠**字号 + 间距 + 字重**拉开，而不是靠颜色：
- 首页 hero（"AI research and products…"）：**粗无衬线 Styrene**，超大、紧字距（negative tracking）。
- 专题大标题（"What 81,000 people want from AI"）：**大号衬线 Tiempos**，优雅、display 级别。
- 文章页标题（"Expanding Project Glasswing"）：**粗无衬线**，居中。
- 正文：衬线 Tiempos，适中测量宽度，行高宽松。

## 3. 文章页版式（Post Layout）

综合 Project Glasswing 截图与真实文章页（Tracing the thoughts…）：

```
        [ Announcements ]        ← 居中·小号·粗·无衬线·分类标签
   Expanding Project Glasswing   ← 居中·大号·粗·无衬线·标题
          2026年6月2日            ← 居中·小号·灰·日期
   ┌───────────────────────┐
   │   [圆角封面图 / 深底]   │     ← 大圆角 hero 图，常用深色画布
   └───────────────────────┘
   Project Glasswing is our…     ← 单栏·衬线正文·适中宽度·宽松留白
   （正文中穿插带说明文字 caption 的配图）
   （清晰的 section 小标题分块）

   ── Related content ──         ← 结尾"相关内容"三连卡片
   [文章 A]   [文章 B]   [文章 C]

   ████████ 深色多列页脚 ████████  ← Products / Solutions / Resources / Company
```

要点：
- **标题区居中**，且有 `分类标签 → 标题 → 日期` 的稳定三段结构。
- **顶部 CTA**（如"Read the paper"）放在标题附近。
- **封面图为大圆角**，常配深色画布，强烈的视觉锚点。
- **正文单栏、适中测量宽度**，为长技术文优化可读性。
- **配图必带说明文字（caption）**，打断大段文字、辅助理解。
- **结尾"Related content"三连**——几乎是每篇文章的固定收尾。
- **深色多列页脚**与浅色正文形成强对比，承载全站导航。

## 4. 强调手法（Emphasis）

- **粗体双下划线**压在关键词上，是站点几乎唯一的"装饰性"手法——它**替代颜色**成为强调机制（见首页"research""products"被双下划线标出）。
- logo 里的**反斜杠 `ANTHROP\C`**：对"AI 底层代码"的致敬，也是品牌唯一的标志性细节。
- 几乎不用阴影、渐变、霓虹等"科技感"特效。

---

## 5. 设计哲学（Principles）

> 信任、协作、清晰。人文使命 + 技术工艺。

1. **学术期刊感，而非落地页**——大量留白、紧凑的衬线标题、刻意回避 AI 品牌泛滥的饱和蓝。
2. **近乎无彩 + 单一保留强调**——把注意力资源攒起来，只在最该出现的地方花掉（冯·雷斯托夫效应的品牌级运用）。
3. **让字体承担性格**——双声部字族 + 字号/间距层级，而非颜色或装饰。
4. **克制的标志性细节**——一个反斜杠、一条双下划线，就够了。
5. **模块化版式 + 一致收尾**——分类标签、封面图、相关内容三连，结构稳定、可预期（Jakob 定律：符合用户既有心智模型）。

---

## 6. 一句话总结

> Anthropic 的设计语言 = **米色羊皮纸 + 黑灰二字色 + 一抹赤陶 + 衬线/无衬线双声部 + 期刊式留白 + 稳定的文章模块**。它的"高级感"不来自加法，而来自**把色彩和装饰攒到极致后只花一次**。
